# Product requirements

- Free reports are publicly readable.
- Premium reports are encrypted before public blob storage.
- Purchases are permanent Aptos receipts tied to the buyer wallet.
- A wallet can recover its library on a different browser without local storage.
- Authors can update metadata and deactivate reports they own.
- Listing and search use an indexed database; chain data remains authoritative.
- Existing registry V1 entries remain available as legacy free reports.
